This PHP script is a web interface to the anaouder software https://github.com/gweltou/anaouder-cli that creates breton language subtitles to a video in breton. The script does create a SRT caption file compatible with Youtube. You can edit the file directly on the web page before downloading it to your computer.
Note that to run this script your web server needs no file upload or runtime limits. A one hour video may take one hour to create the captions. 
It is based on Anaouder -version 0.9.2. For French it is based on vosk-model-fr-0.22. 
To run the caption generator you do need to install anaouder on your web server.
A working version of the script is there : https://abp.bzh/anaouder/istitlan.php
